# Interpretation Guide

## How To Read The Results

The analysis prioritizes biological plausibility plus statistical stability. A candidate gene is more credible when it has:

- enough mutated samples to be interpretable
- a response-enrichment signal that is not solely a sparse-event artifact
- a plausible connection to immune response, antigen presentation, DNA repair, or melanoma biology
- context from TMB or neoantigen load
- support from external data or literature

## What Not To Overclaim

A low p-value in this project does not establish a clinical biomarker. It indicates a candidate association in a public retrospective cohort.

Avoid claiming:

- clinical actionability
- treatment selection utility
- causality
- validation
- mechanism from mutation presence alone

## Strategic Precision-Oncology Framing

The project is strongest when framed as a reproducible exploratory workflow:

1. Start with public clinical-genomic data.
2. Define a transparent clinical endpoint.
3. Build sample-level mutation features.
4. Test response associations with small-cohort-appropriate statistics.
5. Evaluate burden and immune context.
6. Separate candidates from validated biomarkers.
